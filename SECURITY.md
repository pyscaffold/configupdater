# Security policy

## Supported versions

Security fixes are made for the latest release of ConfigUpdater.

## Reporting a vulnerability

Please do **not** report security vulnerabilities in public issues. Instead, use
GitHub's [private vulnerability reporting](https://github.com/pyscaffold/configupdater/security/advisories/new),
which only the maintainers can see. We will get back to you as soon as possible and
coordinate a fix and its disclosure with you.
